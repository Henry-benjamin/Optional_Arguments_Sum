Project Overview: Bubble Sort Visualizer

This project is an interactive algorithm visualizer designed to demonstrate how Bubble Sort works step-by-step using vanilla JavaScript, HTML, and CSS.

Key Features & Workflow:

  • Array Generation: Clicking Generate Array creates a random 5-element array with integers between 1 and 100.
  • Step-by-Step Visualization: Clicking Sort Array generates a timeline of container elements showing every single comparison iteration.
  • Active Element Highlighting: The pair of numbers being evaluated in each step is highlighted with a 2px dashed red border.
  • In-Place Swapping: Out-of-order adjacent elements are swapped using custom comparison logic (isOrdered and swapElements).
  • Final Sorted State: Once the algorithm completes a pass with zero swaps, the fully sorted array is displayed at the end with a 2px solid green border.
